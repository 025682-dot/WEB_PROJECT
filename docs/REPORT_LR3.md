### 3. Обґрунтування інструментів розкладки
1. **Загальний макет (.site-layout) — CSS Grid:** Обрано Grid, оскільки макет сторінки є двовимірним (рядки header, content, footer та стовпці main, sidebar). Використано іменовані області `grid-template-areas`, що робить структуру чистою.
2. **Шапка (.site-header) та навігація (.main-nav ul) — Flexbox:** Обрано Flexbox, оскільки вирівнювання відбувається вздовж однієї горизонтальної осі (розподіл `space-between`, центрування `align-items: center` та відступи `gap`).
3. **Сітка карток (.cards-grid) — CSS Grid:** Використано `repeat(auto-fill, minmax(250px, 1fr))` для гнучкої колоночної розкладки без використання медіа-запитів.
4. **Вирівнювання підвалів карток (.card-footer) — Flexbox:** Усередині картки застосовано flex-колонку, де для `.card-footer` задано `margin-top: auto`. Це притискає кнопку та інформацію до низу картки незалежно від обсягу тексту над нею.

### 4. Розбір випадку перекриття правил із панелі стилів (DevTools)
* При виборі посилання меню `.main-nav a:hover` правило змінює властивість `color: #ffffff`, перекриваючи базове правило `.main-nav a` з `color: var(--color-text)`.
* **Причина:** Селектор псевдокласу `.main-nav a:hover` має специфічність `(0, 2, 1)` (один клас, один псевдоклас, один тег), що є сильнішим за селектор `.main-nav a` зі специфічністю `(0, 1, 1)`.
