## 1. Опис структури дизайн-системи та іменування токенів (`css/tokens.css`)

У проєкті впроваджено архітектуру дизайн-токенів на базі користувацьких властивостей CSS (`CSS Custom Properties`). Токени згруповано за семантичним призначенням:

1. **Колірна палітра HSL:**
   * Базовий кут тону `--primary-hue: 220` (синій спектр бренду) та насиченість `--primary-sat: 85%`.
   * Шкала світлості на 5 кроків: `--color-primary-100` (90%), `--color-primary-300` (70%), `--color-primary-500` (50%), `--color-primary-700` (35%), `--color-primary-900` (20%).
   * Акцентний комплементарний колір: `--color-accent: hsl(35, 90%, 50%)`.
   * Нейтральні токени поверхонь: `--color-bg`, `--color-surface`, `--color-surface-subtle`, `--color-border`.
   * Семантичні токени тексту: `--color-text`, `--color-text-muted`, `--color-text-inverse`.

2. **Типографіка та флюїдні шрифти:**
   * Використано функцію `clamp(min, preferred, max)` для плавного масштабування розміру шрифту від ширини вікна перегляду (`vw`) без стрибків між медіазапитами:
     `--font-size-base: clamp(1rem, 0.95rem + 0.25vw, 1.125rem);`
   * Обмеження максимальної довжини рядка: `--max-text-ch: 65ch` (забезпечує стандартне читабельне навантаження у 60–75 символів).

3. **Просторова сітка та оформлення:**
   * Шкала відступів: `--space-xs` (0.25rem), `--space-sm` (0.5rem), `--space-md` (1rem), `--space-lg` (1.5rem), `--space-xl` (2.5rem).
   * Радіуси скруглення: `--radius-sm` (4px), `--radius-md` (8px), `--radius-lg` (12px).
   * Багаторівневі тіні: `--shadow-sm`, `--shadow-md`.

## 2. Реалізація адаптивності (Mobile-First)

Верстка виконана за принципом послідовного ускладнення (Mobile-First):
1. **Базова ширина (360px - мобільні пристрої):** Одноколонковий вертикальний потік на базі Flexbox, картки каталогу вишикувані в одну колонку (`grid-template-columns: 1fr`), навігаційні елементи переносяться за потреби (`flex-wrap: wrap`).
2. **Контрольна точка 768px (планшетні пристрої):** Медіазапит `@media (min-width: 768px)` трансформує сітку карток каталогу у 2 колонки (`repeat(2, 1fr)`).
3. **Контрольна точка 1280px (десктопні монітори):** Медіазапит `@media (min-width: 1280px)` вмикає двовимірну сітку CSS Grid із сайдбаром праворуч, трансформує картки каталогу у 3 колонки (`repeat(3, 1fr)`) та фіксує максимальну ширину контейнера на `1280px` із центруванням через `margin: 0 auto`.

## 3. Механізм темної теми та збереження стану

Темна тема реалізована без зміни коду розмірки чи стилів компонентів — лише шляхом перевизначення значень самих токенів:
* **Автоматичний режим:** `@media (prefers-color-scheme: dark)` активує темні кольори відповідно до системних налаштувань ОС пристрою.
* **Ручний режим:** Атрибут `:root[data-theme="dark"]` дозволяє примусово встановити темну тему.
* **Збереження вибору:** Скрипт `js/theme.js` обробляє натискання кнопки `theme-toggle` та записує стан у `localStorage` браузера, забезпечуючи збереження вибору після перезавантаження сторінки.
