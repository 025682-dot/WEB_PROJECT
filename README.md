# WEB_PROJECT — Навчальний вебресурс

Навчальний вебпроєкт з курсу «Вебпрограмування», виконаний у Херсонському державному університеті. Ресурс являє собою адаптивний вебсайт із каталогом навчальних дисциплін, формою зворотного зв'язку та підтримкою світлої й темної тем.

---

## 🚀 Основні можливості

- **Семантична розмітка HTML5:** Використання семантичних орієнтирів `<header>`, `<main>`, `<nav>`, `<article>`, `<section>`, `<aside>`, `<footer>`, а також форм із `<fieldset>`, `<legend>` та зв'язками `<label for="...">`.
- **Сучасні верстка макета (CSS Grid & Flexbox):**
  - Загальна каркасна сітка сторінки побудована на **CSS Grid** з іменованими областями (`grid-template-areas`).
  - Адаптивна сітка карток каталогу реалізована за допомогою **CSS Grid** (`repeat(auto-fill, minmax(250px, 1fr))`).
  - Шапка сайту та вирівнювання кнопок усередині карток побудовані на **Flexbox** (`justify-content: space-between`, `margin-top: auto`).
- **Система дизайн-токенів та темний режим (Dark Theme):**
  - Налаштовано HSL-палітру та змінні токенів у файлі `tokens.css`.
  - Динамічне перемикання теми через атрибут `data-theme` на тегу `<html>` із збереженням стану в `localStorage`.
- **Нативна валідація даних:** Форма контактів перевіряється стандартними механізмами браузера завдяки атрибутам `required` та `type="email"`.

## 📁 Структура проєкту

```text
WEB_PROJECT/
├── index.html       # Головна сторінка про вебресурс
├── catalog.html     # Каталог навчальних дисциплін
├── contact.html     # Форма зворотного зв'язку
├── css/
│   ├── tokens.css   # Змінні дизайн-токенів та кольорові палітри
│   └── style.css    # Основні стилі макета, Grid та Flexbox
└── js/
    └── theme.js     # Скрипт перемикання та збереження теми
```
